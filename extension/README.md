# StreamCapture Tab Recorder (Chrome)

macOS only lets screen recorders separate sound per app, so StreamCapture can't pull one Chrome tab's sound away from the others. This extension uses Chrome's own tab capture instead: it records exactly one tab, picture and sound, even while other tabs play.

## Install (once)

1. Open `chrome://extensions` in Chrome.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and choose this `extension` folder.
4. Click the puzzle-piece icon in Chrome's toolbar and pin **StreamCapture Tab Recorder**.

## Use

1. Go to the tab you want to record and press play.
2. Click the StreamCapture button. A red **REC** badge appears. You keep hearing the tab.
3. Click the button again to stop. The video is saved to `Downloads/StreamCapture` and shows up in StreamCapture's Library, ready to convert.

Other tabs can keep playing; they are not recorded. Switching to another tab doesn't change what's recorded. Closing the recorded tab stops and saves the recording.

Only record content you have the rights to record.
